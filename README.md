- Evaluated on the **Hateful Memes Challenge** dataset.  
- In progress as a 14-week PBL project.  

**Tech:** `Python` `PyTorch` `Transformers (BERT)` `CLIP / ResNet`

### [Nanoparticle Toxicity Predictor](https://github.com/Nivedithakatta08/Nanoparticle-toxicity)

**Tech:** `Python` `Scikit-learn` `Random Forest` `SVM` `KNN` `Pandas`
